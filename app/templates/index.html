Security & audit trail

This MVP records key changes, but it does not yet implement user login or role-based authorization. Use only on a trusted local computer; do not expose it to a public network.

Audit entries are append-only through the application UI, but a local database administrator can alter them. For production, add authenticated accounts, role enforcement, backups, and audit integrity controls.
